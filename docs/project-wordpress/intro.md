# 🌐 Complete Guide: Setup WordPress Locally with XAMPP & Expose via Cloudflare Tunnel

> A complete end-to-end guide to set up WordPress locally using XAMPP, expose it online using Cloudflare Tunnel, and configure automatic startup using `.bat` and `.vbs` scripts.

---

## 🧩 Overview

This guide helps you:

- Set up **WordPress** on **XAMPP**
- Expose your local server to the internet using **Cloudflare Tunnel**
- Run the tunnel in the background silently
- Access your site via a custom domain like `https://www.customdomain.com`
